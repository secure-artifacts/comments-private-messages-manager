# FB 评论私信管家 · 单工作页版 v2.12.1

## 本版更新

- **默认“私信成功后继续下一条前等待”改为 10 秒**：新安装插件后默认值就是 10 秒；仍可在控制面板手动调整。
- **默认“同一用户全局冷却时间”改为 72 小时**：同一用户成功私信后，默认 72 小时内不会再次触发私信；仍可手动修改。
- **新增亮色 / 暗色模式切换**：控制台顶部和 Popup 都增加独立的“亮色 / 暗色”按钮。
- **新安装默认亮色模式**：亮色模式使用白色背景、黑色正文、浅灰卡片和边框；暗色模式保留原来的深色界面。
- **主题强调色继续保留**：亮暗模式和蓝青 / 紫罗兰 / 翡翠绿 / 琥珀橙 / 玫瑰红强调色是两套独立设置，可以组合使用。
- **完整备份继续包含历史去重数据**：设置、规则、私信日志、`processedComments`、`userHistory`、失败记录等都会导出，换浏览器导入后可继续避免重复私信。

## 默认策略

- 工作页：1 个，严格串行
- Messenger 私信框打开等待：15 秒
- 发送结果确认等待：30 秒
- 私信成功后继续下一条：**10 秒**
- 无任务扫描间隔：3 秒
- 同一用户全局冷却：**72 小时**
- 最大失败重试：3 次
- 页面定时刷新：5 分钟（可调）
- 评论时间范围：最近 7 天
- 外观模式：**亮色（默认）**
- 主题强调色：蓝青（默认）

## 单工作页处理顺序

1. 打开 Facebook 评论管理工具并切到“所有评论”。
2. 从最新评论开始寻找尚未处理、未处于用户冷却期、未命中反向关键词的评论。
3. 点击“发消息”，等待 Messenger 私信框，写入并发送。
4. 成功后先写入评论去重与用户冷却记录。
5. 等待默认 10 秒，再处理下一条。
6. 没有新评论时按时间继续向下处理最近 7 天内的旧评论。
7. 页面只按控制台设置的分钟周期定时刷新。

## 完整备份包含

- `settings`：插件设置、统计、亮暗模式和主题强调色
- `rules`：反向关键词与私信模板
- `userHistory`：用户最后成功私信时间等冷却记录
- `processedComments`：已处理评论唯一键列表
- `processedCommentMeta`：已处理评论处理原因与元数据
- `failedComments`：失败次数与最后失败原因
- `logs`：评论处理与私信日志

> 更换浏览器时，请使用“配置导入与完整备份”里的完整 JSON 备份。CSV 只用于查看日志，不能恢复去重状态。
